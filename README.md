# Enterprise RAG AI Assistant

An enterprise-oriented GenAI application that allows users to upload PDF documents and ask questions in natural language. It uses Retrieval-Augmented Generation (RAG) to generate context-aware answers grounded in document content.

## Features

- PDF document ingestion and text extraction
- Token-based chunking with overlapping text segments
- Embedding generation for semantic search
- Context-grounded question answering using LLMs
- Source-based citations for answers
- Streaming responses
- Logging and observability

## Tech Stack

- Python
- FastAPI
- LLMs and Embeddings
- Retrieval-Augmented Generation (RAG)
- Vector Database
- Docker

## Learning Objectives

Built as a hands-on learning project to understand RAG architecture, document ingestion, text chunking, embeddings, semantic retrieval, LLM integration, and production-oriented backend concepts.
